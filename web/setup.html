ШАГ 1 ИЗ 4

Как вам удобнее работать?

Начните с комфортного режима. Для большого проекта настройки можно увеличить.

Проверяем доступные вычислители…

Скачаем библиотеки NVIDIA в отдельное окружение Athena. Потребуются интернет, несколько гигабайт на диске и несколько минут. Драйвер видеокарты не изменяется.

Расширенные настройки ресурсов

Бюджет токенов влияет на RAM, но не задаёт жёсткий лимит памяти всего приложения. Лимит GPU относится к памяти вычислителя.

Смысловой индекс запускается отдельно. Поиск по именам и коду доступен без него.

ШАГ 2 ИЗ 4

Где установлена платформа 1С?

Athena использует её для автоматической выгрузки и загрузки изменений.

Выбор платформы отключён, потому что включено «Настроить 1С позже». Снимите галочку ниже, чтобы указать путь или нажать «Обзор».

Нужен 1cv8.exe (толстый клиент). 1cv8c.exe и 1cestart.exe не подходят. Выберите версию, совместимую с вашей базой. При проверке Athena проверяет файл, но не запускает 1С.

ШАГ 3 ИЗ 4

Подключим AI-помощника?

Модель будет отвечать на вопросы по найденным фрагментам вашего проекта.

Можно начать без модели: изучать объекты, редактировать код и искать функции.

Проверка запрашивает список моделей. Код проекта не отправляется, настройки сохраняются только на последнем шаге.

ШАГ 4 ИЗ 4

Всё готово к началу

Проверьте настройки перед сохранением.

Индексация останется приостановленной. Готовые пакеты сохраняются; продолжить расчёт можно в панели «Поиск».

После настройки выберите сохранённую выгрузку или подключите базу 1С для выгрузки.

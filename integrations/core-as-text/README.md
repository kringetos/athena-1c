# Минимальный диалог ввода для Конфигуратора 8.5

Прототип использует загрузчик **Core.As 1.0.2.4**, на котором основан Снегопат. Полный модуль Снегопата не загружается: здесь нет зависимостей от его частного API 1С, перехватов редактора и метаданных.

На установленной **1С 8.5.1.1522 x86** проверены запуск на отдельной пустой базе, появление стандартного VBScript `InputBox` внутри процесса `1cv8.exe`, заполнение поля через API доступности Windows и подтверждение клавишей Enter. После подтверждения Конфигуратор продолжил работать. Имитация набора символов инструментом автоматизации не заполнила поле; ручной набор пользователем отдельно не подтверждён. Поэтому это экспериментальный прототип, а не готовая интеграция редактора.

Диалог однострочный, модальный, появляется один раз при запуске тестового Конфигуратора. Текст остаётся только в памяти скрипта до завершения процесса. Вызовов модели, сети, записи файлов, изменения кода или конфигурации нет.

## Подготовка

1. В отдельную папку распакуйте [Core.As Alpha 1.0.2.4](https://github.com/infostart-hub/core_as_loader/releases/tag/Alpha_1_0_2_4).
2. Скопируйте сюда содержимое папок `modules` и `load` из этой интеграции.
3. Из [Снегопата Alpha19](https://github.com/infostart-hub/snegopat_modul/releases/tag/Alpha19) возьмите только `modules/Snegopat/lib/x86/test.dll` и поместите в `modules/AthenaText/lib/x86/test.dll`. Эта библиотека содержит проверку режима DESIGNER и наличия параметра базы. DLL в Git не включена.
4. В этой папке загрузчика должна оставаться только наша запись `load/athena-text.txt`; полноценный `load/snegopat.txt` не копируйте.
5. Запустите `starter.exe`, затем установленный 32-битный Конфигуратор с отдельной пустой базой. После появления диалога остановите стартер, чтобы он не подключался к следующим сеансам 1С.

На машине разработки папка `.athena/integrations/test-8.5/text-runtime` и пустая база уже подготовлены. При закрытых тестовых процессах можно выполнить `powershell.exe -NoProfile -ExecutionPolicy Bypass -File integrations/core-as-text/Start-Test.ps1`. Скрипт берёт путь платформы из настроек Athena, запускает только подготовленную пустую базу и останавливает свой стартер после подключения. Он не восстанавливает и не открывает пользовательский проект.

## Почему есть задержка

`main()` модуля вызывается слишком рано для внутренних сервисов 1С. Наш прототип вообще не обращается к ним. Он создаёт скрытое служебное окно и запускает стандартный диалог после входа приложения в цикл сообщений через одноразовый таймер 750 мс. Это позволяет завершиться DLL-инициализации перед открытием модального окна.

Следующий этап для полноценного агента — подключить обработку введённого запроса и отображение ответа. Этот прототип пока проверяет только загрузчик и окно ввода; доступа к коду Конфигуратора он не предоставляет.

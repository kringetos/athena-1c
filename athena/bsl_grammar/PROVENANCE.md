# BSL grammar

Source: https://github.com/1c-syntax/bsl-parser/tree/v0.30.0
Commit: `ed6c62a3942e25ef8377b18e08a78b80bb156a43`.
`BSLLexer.g4` and `BSLParser.g4` are distributed under LGPL-3.0-or-later.
Copyright and license headers are preserved; see COPYING.md and COPYING.LESSER.md.
Grammar files are unmodified. The incremental option is specific to the upstream
ANTLR fork; standard ANTLR ignores it and emits a warning. Athena uses full parsing
and caches results by source hash, not incremental parse trees.

Python files are generated by standard ANTLR 4.13.2, with UTF-8 input. No Java is
required to run Athena. Runtime dependency: antlr4-python3-runtime==4.13.2 (BSD).

Regenerate from the project root using an official ANTLR 4.13.2 jar and Java 17+:

```powershell
java -jar antlr-4.13.2-complete.jar -encoding UTF-8 -Dlanguage=Python3 -visitor -no-listener -Xexact-output-dir -o athena/bsl_grammar athena/bsl_grammar/BSLLexer.g4 athena/bsl_grammar/BSLParser.g4
```

Keep generated files and original grammars together so the parser can be rebuilt
or replaced. Changes to Athena's extraction adapter live in ../bsl_index.py.

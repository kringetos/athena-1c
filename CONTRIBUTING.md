# Участие в разработке

Перед изменениями прочитайте:

- [Развёртывание](docs/DEPLOYMENT.md)
- [Архитектуру и инварианты](docs/ARCHITECTURE.md)
- [Инструкцию разработчика](docs/DEVELOPMENT.md)
- [Известные проблемы](docs/KNOWN_ISSUES.md)

Используйте отдельную ветку и тестовый проект. Для PR укажите проблему, итоговое поведение, выполненные проверки и ограничения. Не публикуйте рабочие выгрузки 1С, пароли, API-ключи и локальные данные `.athena`. Не выдавайте тест с заглушкой модели за проверку реальной генерации.
